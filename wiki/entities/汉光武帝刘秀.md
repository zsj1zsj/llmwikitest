# 汉光武帝刘秀

**东汉开国皇帝**（前5年—57年），字文叔，南阳蔡阳舂陵人，汉景帝后裔。庙号**世祖**，谥**光武**（「能绍前业曰光，克定祸乱曰武」），在位建武元年至中元二年（25—57年），年六十二崩于洛阳南宫前殿，遗诏薄葬，葬原陵。

他是中国历史上少数**以「中兴」之名行「重建」之实**的开国者：名义上继承西汉（自认上继元帝），实际上重建了一套与西汉不同的中央体制。详细编年见[[wiki/sources/汉光武帝生平编年|生平编年]]，制度细节见[[wiki/sources/汉光武帝制度与治国|制度与治国]]，史料与评价见[[wiki/sources/汉光武帝史料与评价|史料与评价]]。

## 一、生平主线

| 阶段 | 年份 | 要点 |
| --- | --- | --- |
| 家世与早年 | 前5—22 | 父刘钦为南顿令，兄刘縯（伯升）；「仕宦当作执金吾，娶妻当得阴丽华」；曾务农、游学长安 |
| 舂陵起兵 | 22 | 与刘縯合兵加入反莽，初期屡挫，骑牛上阵 |
| 昆阳之战 | 23 | 以寡击众破王莽主力，新莽军事与合法性同时崩塌 |
| 更始时期 | 23—25 | 兄刘縯被杀而韬晦；持节北渡河北，平王郎，收编铜马等部，得「铜马帝」之号 |
| 称帝定都 | 25 | 六月己未即位于鄗南千秋亭，十月定都洛阳 |
| 统一战争 | 25—36 | 次第平定关东、南方、陇右、巴蜀，河西窦融归附 |
| 建武中后期 | 36—55 | 度田、奴婢诏令、裁并郡县、废郭后立阴丽华、废太子刘强 |
| 晚年 | 54—57 | 拒封禅（54）→ 封禅泰山（56）→ 宣布图谶于天下 → 崩 |

**两次关键转折**：其一，兄长被杀后不以私怨动兵，反以「深引过而已」的姿态取得更始信任，换得北渡河北的机会；其二，河北收编铜马数十万众，「推赤心置人腹中」，才真正拥有争天下的本钱。

## 二、军事

- **昆阳之战（23年）**：王莽军「将兵百万，其甲士四十二万人」——《资治通鉴》点明「定会者四十二万人，号百万」，即**四十二万为实集、百万为号称**。城中仅「八九千人」，汉军总数正史无载。刘秀率十三骑出城求援，又亲率三千敢死队冲其中坚，杀王寻，莽军大溃。
- **统一进程**：关东（刘永、张步、董宪、庞萌、李宪）→ 南方（秦丰、田戎）→ 陇右隗嚣 → 巴蜀公孙述（36年成都降）。**十二年始成**，是其「以缓制猝」用兵风格的体现。
- **用将方式**：与刘邦「诛功臣」相反，光武对功臣**封侯赐邑而不任吏职**，建武十三年「罢左右将军官」，功臣以「特进」「奉朝请」参议——既保其福禄，又收其兵权。

## 三、制度与治国

**退功臣、进文吏**是光武制度设计的核心，可拆为四层：封侯赐邑偿军功（大国不过四县）、罢将军官收兵权、不任吏职、以「峻文深宪」约束在位文吏。结果是「建武之世，侯者百余……终无诛谴者」——代价是功臣的政治能量转向地方豪族与婚姻网络。

**中央体制**：「虽置三公，事归台阁」（仲长统《昌言·法诫篇》语）。尚书台由四曹扩为六曹，三公虚权化，御史中丞、司隶校尉强化。这一格局是东汉政治的起点。

**地方与军事**：建武六年并省四百余县（「吏职减损，十置其一」），初罢郡国都尉官；建武七年罢轻车、骑士、材官、楼船士及军假吏，大规模复员；刺史渐成州级长官（十八年罢州牧置刺史，秩由二千石降六百石）。

**柔道治国**：建武十七年「吾理天下，亦欲以柔道行之」。具体政策包括九道奴婢诏令（建武二年至十四年，含「天地之性人为贵，其杀奴婢，不得减罪」）、减刑、赈济、恢复三十税一、建武二十六年增百官奉。

**儒学与教化**：建武五年初起太学，立五经十四博士，「未及下车，而先访儒雅」；表彰不仕王莽的隐士（严光、周党、王霸），诏称「自古明王圣主必有不宾之士……亦各有志焉」。此举奠定东汉重名节之士风。

**谶纬政治**：以《赤伏符》「刘秀发兵捕不道」为受命依据，据谶超拜王梁为大司空，中元元年「宣布图谶于天下」。桓谭因「臣不读谶」几遭斩，尹敏以增阙文「君无口，为汉辅」而沈滞。谶纬由此成为东汉国家意识形态。

## 四、边疆

- **南匈奴**：建武二十四年匈奴分裂为南北；二十五年南单于称臣，二十六年置使匈奴中郎将，徙南匈奴于西河美稷。
- **西域**：拒绝设置西域都护、退还西域侍子。总纲见报臧宫诏「务广地者荒，务广德者强……苟非其时，不如息人」。
- **羌人**：复置护羌校尉，徙先零羌于天水、陇西、扶风；羌人「皆为吏人豪右所徭役，积以愁怨」，为东汉羌患伏笔。
- **马援**：平交趾（斩征侧、征贰），征武陵五溪蛮时卒于军，死后遭梁松构陷，「宾客故人莫敢吊会」。

## 五、历代评价

传统史学的评价谱系高度一致地推重光武，但各自的着眼点与批评点不同。以下引语均已核到篇卷，完整清单见[[wiki/sources/汉光武帝史料与评价|史料与评价]]。

- **范晔《后汉书》**：赞语以「中兴」许之，并称其内政「斲雕为朴」；对废郭后一事不苛责，谓「恩加别馆，增宠党戚……不亦光于古乎」。《光武帝纪下》另有一句断语，是后世「退功臣」论的源头——「**退功臣而进文吏，戢弓矢而散马牛，虽道未方古，斯亦止戈之武焉**」。
- **袁宏《后汉纪》**（东晋，早于范晔）：评语独立于范书，且对光武有独特批评——认为他受节于更始而自立，「长安犹存，建武之号已立，虽南面而有天下，以为道未尽也」。这提醒「中兴」叙事本身含有合法性建构。
- **王充《论衡》**（东汉当代）：《宣汉篇》「光武中兴，复致太平」，《恢国篇》以周汉相较而扬汉，是当代人的正面评价样本；但其昆阳兵力数字与正史严重不合，反成校勘线索。
- **仲长统《昌言》**（东汉末）：最尖锐的近当代批评——「光武皇帝愠数世之失权，忿强臣之窃命，矫枉过直，政不任下，**虽置三公，事归台阁**。自此以来，三公之职，备员而已……而权移外戚之家，宠被近习之竖。」
- **曹植《汉二祖优劣论》**（曹魏）：专篇比较汉高祖与光武，断语为「**故曰光武其优也**」——这是「光武优于刘邦」说的最早系统表述。
- **诸葛亮**（赖《金楼子·立言篇下》保存）：反驳曹植「光武将谋不如韩、周、良、平」之论，谓「光武策虑深远，有杜渐曲突之明」。
- **唐太宗《贞观政要》**：「朕观古先拨乱之主皆年逾四十，惟光武年三十三」；马周疏则给出「不任功臣」的实际出处——「昔汉光武不任功臣以吏事，所以终全其世者，良由得其术也」。
- **司马光《资治通鉴》**：「自三代既亡，风化之美，未有若东汉之盛者也」，并把东汉「政治虽浊而风俗不衰」归因于「光武、明、章之遗化」。这是「光武奠定东汉士风」这一评价范式的定型文本。
- **顾炎武《日知录》卷十三**：「光武有鉴于此，故尊崇节义，敦厉名实，所举用者莫非经明行修之人，而风俗为之一变……三代以下风俗之美，无尚于东京者。」
- **王夫之《读通鉴论》卷六**：总体判断极高——「三代而下，取天下者，唯光武独焉」「自三代而下，唯光武允冠百王矣」。以「柔道」概括其取天下与治天下之道：「以静制动，以道制权，以谋制力，以缓制猝，以宽制猛」，「柔者非弱之谓也，反本自治，顺人心以不犯阴阳之忌也」。但批评同样尖锐：**废郭后、易太子而倚重阴氏**，斥为「虑以免一时之患，而贻数世之危」，直指东汉外戚之祸（「卒使窦、梁、邓、何相踵以亡汉」）；**徙南匈奴于西河美稷**，「人极之毁，自此始矣」；退吕后配食为「乱之乱者也」；对严光、周党隐逸非议；对马援「寡恩」。其**治盗之法**则获盛赞：「吏虽逗留、回避、故纵者皆勿问，听以禽讨为效……此不易之良法」。
- **赵翼《廿二史札记》**：卷四《东汉功臣多近儒》谓「光武诸功臣，大半多习儒术，与光武意气相孚合」；《光武信谶书》断为「是光武之信谶书，几等于圣经贤传」；《东汉废太子皆保全》归因于「崇儒重道，子弟习于孝友之训者深」；《夫在称太》则批评废郭后后「夫在称太，究属不经」。
- **毛泽东**：网络流传的「最有学问、最会打仗、最会用人」评语**无一手出处**（可追溯的最早公开出处是 2010 年一本图书的宣传语），不宜引作可信评价；较为可据的是他推荐《后汉书》时称「西汉高文、景、武、昭等读起来较有兴味，东汉只有光武可以读」。

**评价谱系的一个观察**：推重者的理由集中在「柔道」「风俗」「保全功臣」，批评者的理由集中在「事归台阁」「倚重外戚」「南匈奴内徙」——即**同一套制度设计，既被读作德政，也被读作东汉百年积弊的起点**。

## 六、须辨正的常见误说

- **「建武三十年（54年）封禅泰山」有误**。54年只是群臣请封禅遭拒（「即位三十年，百姓怨气满腹，吾谁欺，欺天乎」）；封禅实为**建武三十二年（56年）二月辛卯登封泰山、甲午禅梁父**，同年四月改元中元元年。
- **云台二十八将是明帝永平三年（60年）所定，非光武本人所立**，晚于光武之崩三年；马援被排除，《通鉴》归因「以椒房之亲」。
- **昆阳「陨石助战」**：「夜有流星坠营中」确为《后汉书》原文，但属**星占灾异叙事**，科学性存疑，且《资治通鉴》记同一战役时已删去此段。「位面之子」「大魔导师」为网络戏称，不是史料。
- **「闭玉门以谢西域」是范晔论赞措辞，非光武诏令**；相关「议者欲闭玉门、阳关」是安帝朝之事。
- **马援立铜柱不见于《后汉书》**：本传所载是以骆越铜鼓铸「铜马」上献，铜柱属后世传说。
- **生年**：仅知「建平元年十二月甲子」，建平元年即前6年，其十二月已跨入前5年初，通行以前5年为准；具体公历日期待考。
- **赵翼《廿二史札记》并无「光武帝不任功臣以吏事」这一条目**：通检三十六卷目录无此名。该说法的实际出处是《贞观政要》卷三马周疏。
- **「光武之略，非曹公所及」系托名诸葛亮**：遍检文献未见，属网络流传。诸葛亮真评光武之语见《金楼子·立言篇下》，内容是驳曹植，与曹操无关。
- **「唐太宗／魏徵论东汉崇儒」无对应原文**：《贞观政要》全书「光武」仅五处，无一处出自《崇儒学》篇。
- **「刘秀是唯一不杀功臣的开国皇帝」表述过强**：功臣刘隆即曾「坐征下狱」，虽「以功臣特免为庶人」；准确说法是「不任吏职、终无诛谴者」。
- **「陨石召唤」的文本种子确在《后汉书》**（「夜有流星坠营中」），但史书只记为**天象征兆**（李贤注引《续汉志》解为「营头之星」），并未说陨石砸营；《汉书·王莽传下》同记「天风蜚瓦，雨如注水」，可见风雨是双方共同经历的气象事件。
