# 八王之乱小抄

压缩版速记卡，供检索与背诵。详细论证见[[wiki/analyses/八王之乱：制度失控与西晋崩解|八王之乱：制度失控与西晋崩解]]，人物图谱见[[wiki/analyses/八王之乱人物关系|八王之乱人物关系]]。

## 一句话定义

**291—306年**，西晋宗室诸王围绕**皇帝控制权、辅政权、皇位继承权**反复发动的宫廷政变与内战，共约16年。起于291年诛杨骏，阶段终点是306年惠帝返回洛阳、[[wiki/entities/司马越|司马越]]掌政。

## 三、答题因果链（骨架）

宗室军政化 → 惠帝不能决策 → 辅政无边界（杨骏把"夹辅王室"做成"控制皇帝"）→ 禁军＋诏书＝政变工具 → 太子被废杀，**继承确定性消失** → 合法性战争（清君侧／复太子）→ 地方军入主中央 → 皇帝变人质 → 地方军镇化＋流民武装化＋族群政治 → 永嘉之乱 → 316 西晋亡 → 317 东晋南渡。

## 四、必答三个论点

1. **不是"八个王打架"**：八王不同时参战、无固定阵营，是多轮政变、结盟与背叛的总称；《晋书》卷五十九合传正说明其为一段连续权力危机。
2. **根因是制度而非某个人**：司马炎同时要解决"自己皇权安全／惠帝短期过渡／最终过渡到司马遹"三个时间尺度的问题，却没有连成一套制度——强化宗室给了宗王军事资本，辅政安排给了杨骏架空皇帝的工具，而"司马遹"这个继承终点被清除后，所有矛盾失去制度出口。贾后、杨骏是触发者，不是总因。
3. **与五胡十六国不是直接因果**：须经三个中介——① 中央军政失灵、都督刺史军镇化；② 战争饥荒制造流民集团；③ 皇帝权威被反复挟持，使地方武力获得独立合法性。

## 五、易错点与考订

- **司马亮是宣帝第四子**（《晋书》卷三十八母系分组、卷五十九"宣帝第四子"），非第三子；维基百科条目作"第三子"系误。
- **306年是阶段终点，不是乱局终点**：司马越掌政至311年病死，316年西晋才亡。
- **"八王"是后世总称**，非当时固定集团；参与乱事的宗王远不止八人（司马允、司马虓、司马腾、司马模、司马繇、司马肜等）。
- **灭吴后裁撤州郡兵力**（大郡百人、小郡五十人）反而凸显诸王与都督的军事优势，是易被忽略的一环。
- **江统《徙戎论》**是士大夫安全焦虑的表达，不能直接当作"外族必然入侵"的证明；匈奴、氐、羯、鲜卑早已在内迁人口、军队与边疆体系之中。
- **惠帝在位至306年**，并非乱中被废；被废的是太子司马遹。
- **皇帝始终是合法性资源**：诏书、騶虞幡、乘舆服饰反复成为争夺对象，荡阴之后惠帝本人沦为军阀人质。

## 六、关键配角（非司马氏）

- **外戚后妃**：杨骏、杨芷（292年饿死金墉城）、贾南风、贾谧、羊献容、谢玖
- **朝臣**：卫瓘（与亮同被杀）、张华（贾后时期维持朝局，伦政变时被杀）、裴頠
- **谋主与部将**：孙秀（助伦篡位）、张方（杀乂、挟帝西迁，306年被颙所杀）、李含、卢志、刘舆
- **地方势力**：王浚（幽州，联鲜卑乌桓）、司马腾（并州）、刘琨、刘乔、苟晞
- **族群与流民**：刘渊（汉赵）、李特／李流／李雄（成汉）、石勒（先在汲桑集团）
