# Redis 面试题整理

个人面试备忘笔记，2025-03-16。[[raw/articles/redis 面试]]

## 数据类型（9种）
| 类型 | 典型用途 |
|------|----------|
| String | 计数器、缓存简单值 |
| List | 消息队列、任务列表 |
| Set | 标签、去重集合 |
| Sorted Set | 排行榜、滑动窗口限流（`ZCOUNT`/`ZADD`） |
| Hash | 对象存储（用户信息、购物车） |
| Bitmap | 签到记录、布尔值大规模存储 |
| HyperLogLog | 大规模去重计数（精度不高，如 UV 统计） |
| Stream | 实时消息队列、事件溯源 |
| Geospatial | 地理位置查询（附近商铺） |

## 单线程为何性能高？
1. I/O 多路复用：单线程事件循环管理多并发连接
2. 内存操作极快：哈希表、跳表等高效数据结构
3. 原子命令执行：无并发锁开销
4. 无上下文切换开销

## 集群分片机制（Hash Slots）
- 集群固定划分 **16384 个哈希槽**，每个 key 经 CRC16 算法映射到槽
- 槽均匀分配到各节点；3 节点时每节点约 5461 槽
- 客户端访问时若 key 不在当前节点，返回 `MOVED` 错误重定向
- 节点增删时进行槽迁移，客户端透明感知

## 集群高可用
- 每个主节点配置一个或多个从节点
- 主节点故障时自动提升从节点（故障转移）
