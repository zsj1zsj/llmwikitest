# 杨惠之考

**出处：** 西域文明的发现（日本国立情报学研究所数字丝路项目），原载 https://dsr.nii.ac.jp/narratives/discovery/08/index.html.zh，2006年12月发行。作者：大西磨希子。

## 杨惠之其人

盛唐开元年间"塑圣"，与"画圣"吴道子同师张僧繇，二人号为画友，巧艺并著。后吴道子声名大振，杨惠之愤然弃画从塑。《唐语林》："道子画，惠之塑，夺得僧繇神笔路。"

- 生辰忌日不详，籍贯不明确，后世文献多不可靠
- 著有《塑诀》一卷，今已失传
- 所有实物作品千年荡然无存，梁思成《中国雕塑史》仅能据零星记载概述

## 主要作品地域

### 两京、凤翔

| 地点 | 作品 |
|---|---|
| 京兆太华观 | 玉皇像（身披九色螭罗帔，宋代仍为模仿范本） |
| 京兆留杯亭 | 倡优留杯亭像（唯一已知普通人物塑像，从背面即可辨认本人） |
| 汴州安业寺（大相国寺） | 大殿佛像、枝条千佛、二护法神、维摩居士像 |
| 洛阳广爱寺 | 楞伽山（首创"塑壁"技法）、五百罗汉（存疑） |
| 西京千福寺 | 涅槃鬼神壁画 |
| 凤翔天柱寺 | 维摩像 |
| 洛阳玄元观 | 神仙泥塑像（开元二十九年建，天宝元年配老子石雕及诸像） |

**塑壁技法**：在墙壁上堆塑山峦，穿插人物台阁，使之浑然一体。后发展为"影塑"，敦煌莫高窟的泥塑由圆塑渐淡化为高塑、影塑、壁塑，与壁画融为一体。

**五百罗汉存疑**：苏轼、苏辙游广爱寺诗只提及"宝山"（楞伽山），未言罗汉。二苏才学不可能只知宝山不知罗汉，疑刘道醇误听传言。

### 湖南、江苏（存疑）

顾颉刚提出杨惠之"生平未尝渡江"：

- **郴州通惠禅师院**：九子母像（鬼子母与九子，"自地坐立，不以床具"，纯色无华）
- **昆山慧聚寺**：毗沙门天王像、千手观音塑像（文献未肯定作者为杨惠之，且慧聚寺年代距杨惠之百年）

## 唐代考古旁证

文章以丝绸之路出土文物推测杨惠之作品原貌：

- **维摩诘像**：顾恺之即绘维摩像，盛唐名士风流题材；敦煌莫高窟第335窟初唐壁画可见其形象
- **九子母像**：吐鲁番交河古城出土唐代鬼子母彩色麻布画（9世纪前，胡服装扮哺乳婴孩，八子分列嬉戏）
- **毗沙门天王像**：唐玄宗时趋于标准化，"等身像"或更小，渐趋典雅精致；莫高窟第45窟可见实物
- **千手千眼观音**：初唐智通译《千手千眼观世音菩萨陀罗尼神咒经》，武则天曾令宫女绣像；于阗画师尉迟乙僧亦画过；杨惠之开元年间创作此题材完全可能

## 关键引文

> "道子画，惠之塑，夺得僧繇神笔路。" ——《唐语林》

> 画工龙章提议：太华观中尚有唐人杨惠之创作的玉皇像可以效仿。 ——《宋朝名画评》

> 留杯亭像"像成之日，背立者，京兆人皆呼为留杯亭也"。 ——《五代名画补遗》

> "杨惠之以塑工妙天下，为八万四千手眼观音不可措手，故作千手眼，今之作者皆祖惠之。" ——黄震《黄氏日钞》
