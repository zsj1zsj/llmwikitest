# 汉光武帝史料与评价

来源：[[raw/articles/汉光武帝史料与评价]]

## 价值

这一份处理的是「怎么知道」而非「发生了什么」：逐条列出光武帝研究的史料系统（成书年代、作者立场、价值与局限），汇编历代评价的**逐字原文并核到篇卷**，最后给出 **A—E 五级史料可信度分级**。它最有价值之处是把大量网络流传、来源不明的评语做了溯源与证伪，可直接作为下游引用的过滤器。文件另设「未能核实或须纠正的说法」十条，明确标注哪些引语不可信。

## 史料清单要点

- **《东观汉记》**（东汉当代官修）为现存最早的光武记录，保留口语化诏令；已佚，今存辑本。其载退功臣比范晔直白：「帝以天下既定，思念欲完功臣爵土，不令以吏职为过，故皆以列侯就第，恩遇甚厚。」
- **《后汉书·光武帝纪》**（南朝宋·[[wiki/sources/范晔|范晔]]）为定本，李贤注大量征引《东观汉记》佚文。需注意今本「志」实为司马彪《续汉书》，长期被误题为范晔书。
- **袁宏《后汉纪》**（东晋）成书早于范晔，评语独立，且对光武有独特批评。
- **《资治通鉴》卷三十八至四十四**：编年清晰，剪裁服从「教化—风俗」鉴戒主线。
- 结构性局限：**光武研究高度依赖官修史书**。汉碑石刻对光武本人几乎无直接记载，出土简牍亦未提供光武时期文书，缺少独立档案系统的校验。

## 历代评价（均已核到原文）

| 时代 | 评价者 | 要点 |
| --- | --- | --- |
| 南朝宋 | 范晔 | 赞语以「中兴」许之；「**退功臣而进文吏，戢弓矢而散马牛，虽道未方古，斯亦止戈之武焉**」是「退功臣」论的源头 |
| 东汉末 | 仲长统《昌言》 | 最尖锐的近当代批评：「矫枉过直，政不任下，**虽置三公，事归台阁**……而权移外戚之家」 |
| 曹魏 | 曹植《汉二祖优劣论》 | 比较汉高祖与光武，断语「**故曰光武其优也**」 |
| 三国 | 诸葛亮（赖《金楼子·立言篇下》保存） | 反驳曹植「光武将谋不如韩、周、良、平」之说：「光武策虑深远，有杜渐曲突之明」 |
| 唐 | 唐太宗《贞观政要》 | 「朕观古先拨乱之主皆年逾四十，惟光武年三十三」；马周疏「昔汉光武不任功臣以吏事，所以终全其世者，良由得其术也」 |
| 北宋 | 司马光《通鉴》卷六十八臣光曰 | 「自三代既亡，风化之美，未有若东汉之盛者也」——「光武奠定东汉士风」范式的定型文本 |
| 南宋 | 陈亮 | 「自古中兴之盛，无出于光武矣」（经二手转引） |
| 明清之际 | 王夫之《读通鉴论》卷六 | 总体极高：「三代而下，取天下者，唯光武独焉」「自三代而下，唯光武允冠百王矣」；但批评亦多，见下 |
| 清 | 顾炎武《日知录》卷十三 | 「光武有鉴于此，故尊崇节义，敦厉名实……三代以下风俗之美，无尚于东京者」 |
| 清 | 赵翼《廿二史札记》 | 卷四《东汉功臣多近儒》《东汉废太子皆保全》《光武信谶书》等，卷五《东汉尚名节》 |
| 近代 | 梁启超《新民说·论私德》、章太炎 | 章太炎无评光武专条 |

**王夫之的分事判断**（卷六《光武》三十八则）：柔道治国「非徒治天下也，其取天下也，亦是而已矣」；退功臣进文吏「三代以下，君臣交尽其美，唯东汉为盛焉」；度田后的治盗之法「此不易之良法」。批评则集中于：**废郭后、易太子而倚重阴氏**（「虑以免一时之患，而贻数世之危」）、**纳南匈奴入居西河美稷**（「人极之毁，自此始矣」）、退吕后配食（「乱之乱者也」），以及对严光、周党隐逸态度的非议。

## 史料可信度分级

| 级 | 性质 | 例 |
| --- | --- | --- |
| **A 一手/当代** | 东汉当代国史、政论、当事人文书 | 《东观汉记》诏令、《论衡》、仲长统《昌言》、马援评语 |
| **B 后世正史** | 南朝至北宋正史、编年史 | 《后汉书》、《续汉书》八志、《后汉纪》、《通鉴》卷38—44 |
| **C 已核到原文的评论** | 史家论赞与后人评议（评价，非事实） | 范晔、司马光、曹植、诸葛亮、唐太宗、王夫之、顾炎武、赵翼、梁启超 |
| **D 待考／出处不明** | 无法落实到可信文献 | 毛泽东「三个最」、托名诸葛亮的「光武之略非曹公所及」、「唐太宗论东汉崇儒」、赵翼「光武帝不任功臣以吏事」这一条目名 |
| **E 网络传说** | 现代戏称，无史料依据 | 「位面之子」「大魔导师」「陨石召唤」 |

## 须纠正的说法（本文件最重要的产出）

- **毛泽东「最有学问、最会打仗、最会用人」**：无一手出处。可追溯的最早公开出处是 2010 年魏新《东汉开国》的**图书宣传语**，转载媒体均无引注；毛泽东晚年图书管理员徐中远所列《后汉书》批注全条目中亦无此语。
- **赵翼《廿二史札记》并无「光武帝不任功臣以吏事」这一条目**：通检三十六卷目录无此名。「不任功臣以吏事」的实际出处是《贞观政要》卷三马周疏。
- **托名诸葛亮的「光武之略，非曹公所及」**：遍检文献未见，属网络流传。诸葛亮真评见《金楼子》，内容与曹操无关。
- **「唐太宗／魏徵论东汉崇儒」**：《贞观政要》全书「光武」仅五处，无一处出自《崇儒学》篇。
- **王夫之论光武「罢州郡兵」**：核卷六三十八则未见相应条目，二手论著若如此引述须回核。
- **「陨石召唤」的文本种子确在《后汉书》**（「夜有流星坠营中」），但史书只记为**天象征兆**（李贤注引《续汉志》解为「营头之星」），并未说陨石砸营；且《汉书·王莽传下》同记「天风蜚瓦，雨如注水」，说明风雨是双方共同经历的气象事件。
- **「刘秀是唯一不杀功臣的开国皇帝」**：方向正确但表述过强——功臣刘隆即曾「坐征下狱」，虽「以功臣特免为庶人」。

## 史料限制

赵翼《廿二史札记》卷二以下不在维基文库，本文件改据识典古籍所收 CADAL 影印本**OCR**，有可见讹字（如「东海主」当作「东海王」），且为单一来源、未经双源互证，引用前须以中华书局《廿二史札记校证》核字。司马彪、袁宏、薛莹、陈亮评语的**原文**仅见二手论著转引，未回核原书。《论衡·恢国篇》昆阳兵力存在「三万／百万」异文。《后汉书·刘隆传》「颍川、弘农可问」一句亦属转引。
